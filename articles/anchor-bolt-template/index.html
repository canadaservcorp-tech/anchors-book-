How to make and use an anchor bolt template

By Hicham Zein Eddine, Eng. · From Chapter 11 of the Anchor Bolt Field Guide

Short answer: A template is a temporary plywood or steel plate drilled with the exact number, diameter, spacing and arrangement of the column's bolts. It holds the whole bolt group in that pattern while the concrete is cast, and the same template can later be used to drill the base plates, so both ends match.

Anchor bolts cannot be placed by hand and hoped into position. They must sit in the exact pattern the steel column will later bolt down to. The single most important tool for getting this right is the anchor bolt template.

What the template must match

The template is a physical copy of the column's bolt pattern. It must mirror the base connection hole for hole:

  • The same number of holes as bolts in the column base.
  • The same diameter as the bolts, so each bolt is held snugly and cannot wander.
  • The correct spacing between the bolts.
  • The correct disposition (arrangement), in the same layout the column base requires.

Mark the centre with a nail

The holes fix the pattern; the template still has to sit in the right place on the footing. Put a nail in the exact centre of the template. The surveyor and the engineer line this centre nail up with the surveyed column centre point when positioning the template.

The template serves twice

Do not throw the template away after the pour. It is a precise record of the bolt pattern, so use it as the drilling reference when the column base plates are fabricated. One pattern, one reference: the plate holes line up with the bolts already cast in, and you avoid measuring the same pattern twice from the drawing.

On site

  1. Fabricate the template from the base-plate detail on the drawing.
  2. Measure every bolt with a caliper before it goes into the template.
  3. Fit two nuts and two washers per bolt, one set below the template and one above.
  4. Mark the centre nail and align it with the surveyed column point.
  5. Keep the template for the base-plate fabricator.

Questions engineers ask

What is an anchor bolt template made of?
Plywood or metal. It is a temporary plate drilled with holes that match the column base plate's bolt pattern.
Can the anchor bolt template be reused?
Yes. Keep it and use it as the drilling reference for the column base plates, so the plate holes match the bolts already cast in the foundation.
How is the template positioned on the footing?
With a nail in the exact centre of the template, aligned with the surveyed column centre point.
